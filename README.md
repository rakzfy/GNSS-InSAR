The input file ‘Pline’ and ‘Eline’ in the code are the file names of your DInSAR LOS displacement file.
For example, DA1239.tif is a Ascending track DInSAR LOS displacement file; DASAR.tif is the Descending track DInSAR LOS displacement file;
M1239.tif is the ascending track MAI-InSAR LOS displacement file; M0969.tif is the Descending track MAI-InSAR LOS displacement file;
ILOS1239.tif is the ascending track incidence angle file; ILOS0969.tif is a descending incidence angle file;
Precision1239.tif is the ascending track DInSAR LOS displacement accuracy file; Precision0969.tif is the descending track DInSAR LOS displacement accuracy file;
Precisionmai1239.tif is the ascending track MAI-InSAR LOS displacement accuracy file; Precisionmai0969.tif is the descending track MAI-InSAR LOS displacement accuracy file;
GPS1239e.tif is E component GPS displacement file; GPS1239n.tif is N component GPS displacement file; GPS1239u.tif is U component GPS displacement file;

The raw data occupies a large amount of memory, and users who need it can leave a message.
